# NetSentinel
NetSentinel is a Python-based home network security and backup monitoring tool. It provides Wi-Fi discovery, local device monitoring, network security checks and SHA-256 backup integrity verification through a simple Windows graphical interface. Designed for defensive cybersecurity and authorised testing.

NetSentinel's main purpose is to help users monitor their home network security and verify the integrity of their backups. It provides tools for Wi-Fi discovery, local device identification, basic security assessments and backup verification, helping users detect potential issues and improve their network resilience.

NetSentinel helps users protect their home networks and important data by making network activity easier to understand, identifying potential security weaknesses and verifying that backup files are intact and ready for recovery when needed.
